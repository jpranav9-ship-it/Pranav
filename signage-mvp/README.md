# Signage MVP

Temporary brand: **Signage**

A quote-first landing page for a signage / flex printing / event boards / repair business.

## Current flow

Landing page -> quote form -> WhatsApp -> manual quote -> manual partner fulfilment.

## Before launch

1. Replace `whatsappNumber` in `app.js` with the business WhatsApp number.
2. Replace the temporary brand name in `app.js`.
3. Connect the `signage-mvp` directory as the root directory in the hosting provider, or deploy it as a static site.
4. Add the final domain once the brand is selected.

No public pricing is intentionally shown.
